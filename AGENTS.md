# Agent instructions

## Documentation maintenance

- Every code, configuration, deployment, or user-facing behavior change MUST update the relevant documentation in the same change.
- Keep [`ARCHITECTURE.md`](ARCHITECTURE.md) current with the implemented architecture, hosting, integrations, data flows, API routes, and user-visible features. Update it whenever any of those change.
- Keep the setup, deployment, and testing instructions in [`README.md`](README.md) aligned with the actual configuration and workflows.
